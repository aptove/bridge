# aptove-bridge-core

Core library crate for [Aptove Bridge](https://github.com/aptove/bridge).

This crate provides the open source core library used by `Aptove Bridge` (the OSS binary). 

The public API may change between releases without notice.

For documentation, installation, and usage see the main repository: [github.com/aptove/bridge](https://github.com/aptove/bridge).
