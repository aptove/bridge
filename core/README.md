# aptove-bridge-core

Internal library crate for [aptove-bridge](https://github.com/aptove/bridge).

This crate is not intended for direct use. It provides the shared core used by `aptove-bridge` (the OSS binary) and `bridge-ent` (the enterprise binary). The public API may change between releases without notice.

For documentation, installation, and usage see the main repository: [github.com/aptove/bridge](https://github.com/aptove/bridge).
